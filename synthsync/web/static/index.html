config.txt

Some of config.txt, the file on the Pico that says how it is wired, couldn't be used. SynthSync uses its own setting in place of each line below. Put the file right, then unplug the Pico and plug it in again.

    Clock

    How many pulses output 1 sends on each beat (PPQN). Every other output is a ratio of it. 4 suits most step sequencers: one step for each 16th note.

    Look

    How this page looks on this phone. Every phone keeps its own choice.

    WiFi

      SynthSync's own network

      SynthSync's own network starts again with the new password, so anything joined to it has to join again.

      Start again

      Every setting goes back to how a new SynthSync has it. Your WiFi is forgotten, and SynthSync's own network comes back with the password synthsync. The clock carries on as it is.
